# نظام الحضور والانصراف أونلاين — شركة الفرقان

هذا مشروع ويب يعمل من المتصفح على موبايلات الموظفين، ولوحة الإدارة على اللاب. لا يستخدم Google Sheets.

## مهم قبل الاستخدام الحقيقي
- المشروع يحتاج قاعدة بيانات PostgreSQL مستضافة، واستضافة Node.js. لا يكفي تشغيله على اللاب إذا أردت أن تصل تسجيلات كل الموبايلات إلى نفس المكان.
- إحداثيات الفروع تبدأ فارغة عمدًا. يجب إدخال Latitude وLongitude الحقيقيين من لوحة الإدارة. لا تعتمد على إحداثيات تقريبية.
- يلزم اختبار GPS فعليًا على الموبايل، ثم مراجعة الأمان قبل استخدامه في الشركة.
- هذا مشروع بداية قابل للتطوير، وليس تدقيقًا أمنيًا أو منتجًا تم اختباره ميدانيًا.
- لا تحفظ محاولات التسجيل المرفوضة. الموظفون لا يستطيعون قراءة سجل الحضور؛ واجهات السجل محمية بتسجيل دخول الإدارة.

## المتطلبات
- Node.js 20 أو أحدث.
- قاعدة PostgreSQL مستضافة.
- Visual Studio Code.

## التشغيل محليًا
1. فك ضغط الملف وافتح مجلد المشروع في VS Code.
2. افتح Terminal داخل VS Code.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
5. ضع بيانات PostgreSQL في `DATABASE_URL`.
6. غيّر `SESSION_SECRET` إلى سلسلة عشوائية طويلة، وغيّر `ADMIN_PASSWORD` إلى كلمة سر قوية وفريدة.
7. نفّذ `npm start`.
8. افتح `http://localhost:3000` لصفحة الموظف، و`http://localhost:3000/admin` للوحة الإدارة.

## النشر أونلاين
1. أنشئ قاعدة PostgreSQL لدى مزود استضافة موثوق.
2. ارفع ملفات المشروع إلى مستودع Git خاص أو منصة استضافة Node.js.
3. أنشئ Web Service لتشغيل `npm start`.
4. أضف متغيرات البيئة من `.env.example` إلى إعدادات الاستضافة، ولا ترفع `.env` أو كلمات السر إلى Git.
5. استخدم رابط HTTPS الناتج؛ تحديد الموقع الجغرافي على الهاتف يحتاج HTTPS أو localhost.
6. ادخل إلى `/admin`، أضف الموظفين واضبط إحداثيات الفروع ونطاق كل فرع.
7. جرّب تسجيلًا ناجحًا من موبايل داخل النطاق، ومحاولة خارج النطاق، وتأكد أن المحاولة المرفوضة لا تظهر في السجل.

## التنبيه على الموبايل (اختياري)
يمكن إعداد إشعارات Telegram:
1. أنشئ بوت عبر BotFather في Telegram واحصل على `TELEGRAM_BOT_TOKEN`.
2. استخرج `TELEGRAM_CHAT_ID` لحساب/مجموعة الإدارة، وابدأ محادثة مع البوت.
3. أضف المتغيرين في إعدادات الاستضافة ثم أعد تشغيل الخدمة.
لا تشارك توكن البوت أو كلمات السر مع الموظفين. بدون المتغيرين، لوحة الإدارة والسجل يعملان لكن لا تُرسل رسائل Telegram.

## إدارة البيانات
- أضف الموظفين من لوحة الإدارة، مع كود ورقم سري لكل موظف.
- خزّن أرقام PIN بطريقة hash، ولا تظهر أرقام الموظفين السرية داخل اللوحة.
- صدّر CSV وافتحه باستخدام Excel عند الحاجة.
- فعّل النسخ الاحتياطي لقاعدة البيانات من مزود الاستضافة.
- غيّر كلمة سر الإدارة بعد أول دخول، ولا تشارك رابط الإدارة وكلمة السر مع الموظفين.

## الملفات
- `server.js`: API وقواعد التحقق وحفظ البيانات.
- `public/index.html`: واجهة الموظفين.
- `public/admin.html`: لوحة الإدارة.
- `.env.example`: أسماء إعدادات التشغيل دون أسرار حقيقية.
